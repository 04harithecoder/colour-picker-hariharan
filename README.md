## ✨ About The Project

**Colour Picker** is a lightweight React-based web application designed to provide an easy and interactive way to work with colours.

The project was developed as part of a **React laboratory examination** and was later enhanced and deployed as a live web application.

The goal was simple:

> **Pick a colour → Preview it → Get the colour value. 🎨**

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/04harithecoder/colour-picker-hariharan.git
```

### 2️⃣ Navigate to the Project

```bash
cd colour-picker-hariharan
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Development Server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.

---

## 🏗️ Build For Production

To create a production build:

```bash
npm run build
```

The optimized production files will be generated inside:

```text
dist/
```

---

## 🌐 Deployment

This project is deployed using **two different deployment platforms**.

### 🚀 Render

The production deployment is hosted on Render:

**https://free-colour-picker.onrender.com/**

Render is connected to the GitHub repository, allowing the application to be rebuilt and deployed when changes are pushed to the configured branch.

### 🟢 GitHub Pages

A second deployment is available through GitHub Pages:

**https://04harithecoder.github.io/colour-picker-hariharan/**

This deployment uses the Vite production build and the `gh-pages` package.
